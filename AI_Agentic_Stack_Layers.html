ทำไมต้องมี Integration Layer

Agent ไม่ได้เชื่อมเข้าระบบธุรกิจโดยตรง — ต้องผ่านโปรโตคอลกลาง (MCP/API/OAuth) เสมอ นี่คือชั้นที่ทำให้ Agent ตัวเดียวคุยกับระบบไหนก็ได้ โดยไม่ต้องเขียนโค้ดเชื่อมทีละระบบ

อ่านลำดับชั้นยังไง

Agent Layer — สมองที่สั่งงาน
Integration — ท่อเชื่อมมาตรฐาน
Application — เครื่องมือธุรกิจ
Data — ที่เก็บข้อมูล/ไฟล์
Infrastructure — ฐานรากคลาวด์
อิงโครงสร้าง Layered / N-Tier Architecture ที่ใช้ทั่วไปในระบบองค์กร — แยกความรับผิดชอบแต่ละชั้นชัดเจน เปลี่ยนชั้นหนึ่งไม่กระทบชั้นอื่น
